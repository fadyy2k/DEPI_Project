Network-security design project from the DEPI Cisco Cybersecurity Engineer track.

## Deliverables

- **`Project 6 -Group 2.pkt`** — Cisco Packet Tracer topology
- **`Project 6 -Group 2.pdf`** — project documentation / presentation

## Scope

This repository is an evidence repository for the network-security lab and its documentation. It is intentionally kept separate from my DevSecOps/Kubernetes work so the networking and cybersecurity material can be reviewed on its own.

## How to Review

1. Open the PDF for the documented design and implementation decisions.
2. Open the `.pkt` file in Cisco Packet Tracer to inspect the topology and configuration.
3. Treat any addressing, accounts, or credentials inside the lab as training-only values.

## Security Note

No production infrastructure, company credentials, or customer data should be stored in this repository. Public labs are isolated from operational environments.
